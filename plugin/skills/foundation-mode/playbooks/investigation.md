# Investigation

**You own the answer.** Investigations are read-only. They produce a cited explanation or a recommendation, not a code change.

1. Route through [how](../../how/SKILL.md). For motivation or history, also route through [why](../../why/SKILL.md).
2. Produce the how-shaped output (Overview, Key concepts, How it works, Where things live, Gotchas), or, for a choice between alternatives, a recommendation with a tradeoffs table.
3. Apply [unslop](../../unslop/SKILL.md) to the reply.

No PR and no [architect](../../architect/SKILL.md) unless the investigation precedes a code change. If it does, finish the answer, then route to [Bug fix](bug-fix.md) or [Feature](feature.md).

**Reply:** the investigation output. For "are we sure?" questions, give your real judgment with reasons, and push back if the premise is wrong.
